# Amazon Sales EDA 📊

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on an Amazon product dataset using Python. The main objective is to understand the dataset, clean and preprocess the data, analyze missing values, and visualize important patterns.

## 🎯 Objectives

- Understand the Amazon sales dataset
- Perform data cleaning and preprocessing
- Handle missing values
- Identify duplicate records
- Analyze product prices and ratings
- Create data visualizations
- Perform correlation analysis
- Apply grouping and aggregation
- Perform statistical analysis

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn

## 📂 Project Files

- `amazon.csv` – Dataset
- `Amazon Sales EDA.ipynb` – Jupyter Notebook
- `README.md` – Project Documentation

## 🔍 Project Workflow

### 1. Data Loading and Exploration

- Load the dataset using Pandas
- Display the first five rows
- Check dataset shape
- Inspect data types
- Generate descriptive statistics

### 2. Data Cleaning

- Handle missing values
- Convert price columns into numeric format
- Clean discount percentage values
- Convert rating and rating count into numeric types
- Check duplicate records

### 3. Data Visualization

- Scatter plot
- Histogram
- Correlation heatmap
- Missing value visualization

### 4. Data Analysis

- Correlation analysis
- Grouping and aggregation
- Pivot tables
- Statistical hypothesis testing
